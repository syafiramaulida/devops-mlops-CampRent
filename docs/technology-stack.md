# Technology Stack CampRent

## 1. Deskripsi
CampRent merupakan sistem informasi reservasi camping yang membantu pengguna mencari informasi dan melakukan pemesanan paket camping.

## 2. Teknologi yang Digunakan

- HTML: Membuat struktur halaman website.
- CSS: Mengatur tampilan website.
- JavaScript: Menambahkan interaksi pada website.
- PHP: Mengelola proses di sisi server.
- MySQL: Menyimpan data pengguna, paket camping, dan reservasi.
- Git dan GitHub: Mengelola kode program dan kolaborasi kelompok.

## 3. Tujuan Penggunaan
Teknologi tersebut digunakan untuk mendukung pengembangan sistem reservasi camping CampRent.

## 4. Kesimpulan
Pemilihan teknologi disesuaikan dengan kebutuhan pengembangan CampRent agar sistem mudah digunakan dan dikembangkan.
