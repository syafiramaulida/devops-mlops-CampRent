# Analisis Kebutuhan Sistem CampRent

## 1. Deskripsi Sistem

CampRent merupakan sistem informasi reservasi camping yang membantu pengguna mencari informasi dan melakukan pemesanan paket camping dengan lebih mudah.

## 2. Kebutuhan Pengguna

Pengguna dapat:
- Melihat daftar paket camping.
- Melihat informasi dan harga paket.
- Melakukan reservasi camping.
- Melihat riwayat pemesanan.

## 3. Kebutuhan Admin

Admin dapat:
- Mengelola data paket camping.
- Mengelola data reservasi.
- Melihat data pengguna.
- Mengelola informasi website.

## 4. Tujuan Pengembangan

Membuat sistem reservasi camping yang memudahkan proses pencarian informasi dan pemesanan paket camping.
