# Alur Sistem Reservasi CampRent

## 1. Deskripsi
CampRent merupakan sistem informasi yang membantu pengguna mencari dan memesan paket camping secara online.

## 2. Alur Pengguna

1. Pengguna membuka website CampRent.
2. Pengguna melihat daftar paket camping.
3. Pengguna memilih paket yang diinginkan.
4. Pengguna melihat detail dan harga paket.
5. Pengguna mengisi formulir reservasi.
6. Pengguna mengirimkan data pemesanan.
7. Pengguna dapat melihat riwayat pemesanan.

## 3. Alur Admin

1. Admin masuk ke halaman admin.
2. Admin mengelola data paket camping.
3. Admin memeriksa data reservasi.
4. Admin mengelola informasi pemesanan.
5. Admin memperbarui informasi website jika diperlukan.

## 4. Tujuan
Dokumentasi ini dibuat untuk menjelaskan proses penggunaan CampRent dari sisi pengguna dan admin.
