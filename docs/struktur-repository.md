# Struktur Repository CampRent

Repository ini digunakan untuk pengembangan CampRent, yaitu sistem informasi reservasi camping.

Berikut struktur folder yang digunakan:

- README.md: informasi dan deskripsi project.
- .gitignore: daftar file yang tidak perlu diunggah ke GitHub.
- docs/: tempat menyimpan dokumentasi project.
- src/: tempat menyimpan kode sumber project.
- admin/: halaman untuk admin.
- user/: halaman untuk pengguna.
- api/: tempat menyimpan file API.
- database/: tempat menyimpan file database.
- css/: file untuk mengatur tampilan website.
- js/: file JavaScript untuk fungsi website.
- img/: tempat menyimpan gambar.
